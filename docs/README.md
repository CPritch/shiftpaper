# shiftpaper docs

- [Configuration](configuration.md): what's in config.toml, including a different wallpaper per monitor
- [Transitions](transitions.md): the ways one wallpaper can change into the next
- [Depth models](models.md): which model bakes your wallpapers, and where files go
- [Troubleshooting](troubleshooting.md): logs, and fixes for common problems

Every command has its own help, with examples:

```
shiftpaper help
shiftpaper help slideshow
```

The AUR packages also install man pages (`man shiftpaper`, `man shiftpaperd`) and tab completion for bash, zsh and fish.
